# Uncrate

Optimized RSS feed for [Uncrate](https://uncrate.com): branded icon, RSS summaries, category labels, and purchase links when available.

**Reader mode:** Tapestry does not expose a connector setting for this. In the app, edit the feed and set **Open Links In** to **Reader Mode**.

**More info:** [github.com/newtosh/tapestry-connectors](https://github.com/newtosh/tapestry-connectors)
