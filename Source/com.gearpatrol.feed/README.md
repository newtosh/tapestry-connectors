# Gear Patrol

Optimized RSS feed for [Gear Patrol](https://www.gearpatrol.com): branded icon, article summaries, hero images, and retailer buy links when present.

**Reader mode:** In Tapestry, edit the feed and set **Open Links In** to **Reader Mode**.

**More info:** [github.com/newtosh/tapestry-connectors](https://github.com/newtosh/tapestry-connectors)
